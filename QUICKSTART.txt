  你需要准备什么？
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. 一台电脑（Windows / macOS / Linux 均可）作为服务器
     └─ 安装 Node.js 18+ （https://nodejs.org）

  2. 一台 Android 手机作为被控端
     └─ Android 7.0+
     └─ 需开启"无障碍服务"（App 内有引导）

  3. 一台手机作为控制端（Android 或 iOS 均可）

  4. 构建 APK 需要 Flutter SDK（仅编译时需要）
     └─ https://docs.flutter.dev/get-started/install

  所有设备需在同一局域网内（连同一个 WiFi）

  三步跑起来
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ┌─ 第一步：启动服务器 ─────────────────────────────┐
  │                                                   │
  │   Windows:  双击 start-server.bat                 │
  │   macOS/Linux:  ./start-server.sh                 │
  │                                                   │
  │   启动后会在屏幕上显示本机 IP 地址，例如:           │
  │     192.168.1.100:8080  (以太网)                  │
  │     192.168.1.101:8080  (WiFi)                    │
  │                                                   │
  │   记下其中一个 IP 地址（推荐 WiFi 那个）           │
  └───────────────────────────────────────────────────┘

  ┌─ 第二步：安装 App ──────────────────────────────┐
  │                                                   │
  │   方式 A：已有编译好的 APK                         │
  │     → 直接将 release/remote-control.apk            │
  │       传到手机安装                                  │
  │                                                   │
  │   方式 B：自行编译                                  │
  │     Windows:  双击 build-android.bat               │
  │     macOS/Linux:  ./build-android.sh               │
  │     → 编译完成后 APK 在 release/ 目录              │
  │                                                   │
  │   注意：安装时手机需允许"未知来源"安装             │
  │   控制端和被控端都需要安装同一个 APK                │
  └───────────────────────────────────────────────────┘

  ┌─ 第三步：在 App 中配置服务器 ────────────────────┐
  │                                                   │
  │   1. 打开 App，点击右上角齿轮图标 ⚙               │
  │   2. 输入第一步记下的 IP 地址和端口                │
  │   3. 点击"保存并连接"                             │
  │   4. 返回主页，看到"已连接到服务器"即成功          │
  │                                                   │
  │   控制端和被控端都填同一个服务器地址               │
  └───────────────────────────────────────────────────┘

  开始远程控制
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  【被控端操作】
    1. 点击「允许被控制」
    2. 屏幕上会显示你的设备 ID（如 RC 123 456 789）
    3. 将这个 ID 告诉控制端
    4. 按提示在系统设置中开启「无障碍服务」
       （这是触控模拟的前提条件，App 内有跳转按钮）

  【控制端操作】
    1. 点击「远程控制」
    2. 输入被控端的设备 ID
    3. 被控端会弹出连接请求 → 点「接受」
    4. 远程屏幕自动显示，可以直接触控操作

  【控制端功能】
    ├─ 触控屏幕    → 远程点击/滑动
    ├─ 双指缩放    → 远程缩放
    ├─ 虚拟按键    → 返回/Home/最近任务/锁屏
    ├─ 唤醒按钮    → 远程唤醒被控端屏幕
    └─ 状态栏      → 实时显示延迟和 FPS

  常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Q: 服务器启动后手机连不上？
  A: 确保手机和电脑在同一个 WiFi/局域网。
     检查电脑防火墙是否放行了 8080 端口。

  Q: 被控端无法开启无障碍服务？
  A: 部分国产 ROM 需要额外设置：
     - 小米：设置 → 更多设置 → 无障碍 → 已下载的服务
     - 华为：设置 → 辅助功能 → 无障碍 → 已安装的服务
     - 可能需要关闭"省电优化"对本 App 的限制

  Q: 屏幕画面卡顿？
  A: 修改 lib/config/app_config.dart 中：
     - screenCaptureFps: 降低到 10
     - jpegQuality: 降低到 30
     - maxFrameWidth: 降低到 480
     然后重新编译 APK

  Q: iOS 能作为被控端吗？
  A: 受 Apple 沙盒限制，iOS 只能作为控制端使用。
     iOS 作为被控端无法实现系统级屏幕捕获和触控模拟。

  Q: 公网如何使用？
  A: 将服务器部署到云服务器（阿里云/腾讯云等），
     使用公网 IP 或域名，App 设置中填入公网地址即可。
     生产环境建议开启 SSL（设置中勾选 wss://）。
